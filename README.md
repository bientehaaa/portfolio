# Alireza Kazemzadeh — Portfolio

A dependency-free static portfolio site for a Business Analyst and Business Systems Analyst.

## Structure

- `index.html` — homepage
- `about.html` — positioning and approach
- `case-studies.html` — case-study placeholders
- `artifacts.html` — business-analysis artifact categories
- `skills.html` — capability areas
- `consulting.html` — future consulting focus
- `contact.html` — contact details placeholder
- `assets/css/styles.css` — shared responsive styling
- `assets/js/main.js` — accessible mobile-navigation behavior

## Local preview

Open `index.html` in a browser, or serve the repository from any static file server.

## GitHub Pages

This site needs no build step, database, backend, or custom booking system. In repository settings, choose **Pages**, select the `main` branch and the repository root, then save. Add an approved contact method and one Calendly link later by editing `contact.html` and `consulting.html`.
